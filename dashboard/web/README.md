# Dashboard - Next.js Application

## Setup

```bash
cd dashboard/web
npm install
npm run dev
```

## Structure

```
web/
├── app/              # Next.js app router
├── components/       # React components
├── lib/             # Utilities
├── public/          # Static assets
└── styles/          # CSS/Tailwind
```

## Pages

- `/` - Overview dashboard
- `/activity` - Activity analysis
- `/recovery` - Recovery metrics
- `/share` - Generate shareable images
